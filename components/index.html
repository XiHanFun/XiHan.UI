组件总览 ​

104 个组件，每个都同时提供无头内核（@xihan-ui/headless）、Vue 组件（@xihan-ui/vue）、自定义元素（@xihan-ui/web-components）与默认皮肤（@xihan-ui/styles）四份产物。四者同源：内核是唯一的行为定义，另外三份不重新实现任何逻辑。

本册每个组件一页，页内固定为：产物 · 示例 · 解剖 · Props · 状态机 · connect API · 键盘。除示例外全部由组件源码生成，不会与代码对不上。
