手风琴 accordion ​

数据展示组件。三层同源：无头内核给出解剖与状态机，Vue 组件与自定义元素只是它的两层外壳，行为完全一致。

示例 ​

基础用法 ​

默认单开：展开一项即收起其余，defaultValue 只给初始值，之后由组件自己维护

装 @xihan-ui/vue 与 @xihan-ui/styled 两个包，皮肤单独引一次。

皮肤只认 data-part 与 data-state，覆写同名令牌即可。

方向键只在标题之间搬焦点，永不进内容区，首尾不回绕。 
<script setup lang="ts">
import {
  XhAccordionContent,
  XhAccordionHeader,
  XhAccordionItem,
  XhAccordionRoot,
  XhAccordionTrigger,
} from "@xihan-ui/vue";
</script>

<template>
  <div style="width: 100%; max-width: 420px">
    <XhAccordionRoot :default-value="['install']">
      <XhAccordionItem value="install">
        <XhAccordionHeader>
          <XhAccordionTrigger>怎么安装</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>
          装 @xihan-ui/vue 与 @xihan-ui/styled 两个包，皮肤单独引一次。
        </XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="theme">
        <XhAccordionHeader>
          <XhAccordionTrigger>怎么换皮肤</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>
          皮肤只认 data-part 与 data-state，覆写同名令牌即可。
        </XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="a11y">
        <XhAccordionHeader>
          <XhAccordionTrigger>键盘怎么走</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>
          方向键只在标题之间搬焦点，永不进内容区，首尾不回绕。
        </XhAccordionContent>
      </XhAccordionItem>
    </XhAccordionRoot>
  </div>
</template>

多项展开 ​

multiple 允许多项并存，展开集合恒为 string[]，用 v-model:value 拿到它

value、defaultValue、multiple。

orientation 决定方向键走哪条轴，默认 vertical。

value-change 携带 { value }，update:value 携带裸数组。
展开：basic、size
<script setup lang="ts">
import { ref } from "vue";
import {
  XhAccordionContent,
  XhAccordionHeader,
  XhAccordionItem,
  XhAccordionRoot,
  XhAccordionTrigger,
} from "@xihan-ui/vue";

const panels = ref<string[]>(["basic", "size"]);
</script>

<template>
  <div style="width: 100%; max-width: 420px; display: grid; gap: 12px">
    <XhAccordionRoot v-model:value="panels" multiple>
      <XhAccordionItem value="basic">
        <XhAccordionHeader>
          <XhAccordionTrigger>基础属性</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>value、defaultValue、multiple。</XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="size">
        <XhAccordionHeader>
          <XhAccordionTrigger>排版</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>
          orientation 决定方向键走哪条轴，默认 vertical。
        </XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="events">
        <XhAccordionHeader>
          <XhAccordionTrigger>事件</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>
          value-change 携带 { value }，update:value 携带裸数组。
        </XhAccordionContent>
      </XhAccordionItem>
    </XhAccordionRoot>
    <span>展开：{{ panels.length ? panels.join("、") : "（无）" }}</span>
  </div>
</template>

允许全收 ​

单开模式下最后一项默认收不起来，加 collapsible 才能把它也收上

点当前展开项的标题，它会收起，展开集合变成空数组。

展开它会把上一项挤掉，单开模式一次只留一项。
<script setup lang="ts">
import {
  XhAccordionContent,
  XhAccordionHeader,
  XhAccordionItem,
  XhAccordionRoot,
  XhAccordionTrigger,
} from "@xihan-ui/vue";
</script>

<template>
  <div style="width: 100%; max-width: 420px">
    <XhAccordionRoot :default-value="['one']" collapsible>
      <XhAccordionItem value="one">
        <XhAccordionHeader>
          <XhAccordionTrigger>再点一次就收起</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>点当前展开项的标题，它会收起，展开集合变成空数组。</XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="two">
        <XhAccordionHeader>
          <XhAccordionTrigger>另一项</XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>展开它会把上一项挤掉，单开模式一次只留一项。</XhAccordionContent>
      </XhAccordionItem>
    </XhAccordionRoot>
  </div>
</template>

指示器与禁用 ​

indicator 的朝向由 data-state 驱动，禁用项点不动、方向键也跳过它

标题右侧那个箭头就是 indicator，展开时自动翻转。

这一项展不开。

从第一项按方向键，会直接跳到这里。
<script setup lang="ts">
import {
  XhAccordionContent,
  XhAccordionHeader,
  XhAccordionIndicator,
  XhAccordionItem,
  XhAccordionRoot,
  XhAccordionTrigger,
} from "@xihan-ui/vue";
</script>

<template>
  <div style="width: 100%; max-width: 420px">
    <XhAccordionRoot :default-value="['ready']">
      <XhAccordionItem value="ready">
        <XhAccordionHeader>
          <XhAccordionTrigger>
            <span>已发布</span>
            <XhAccordionIndicator />
          </XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>标题右侧那个箭头就是 indicator，展开时自动翻转。</XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="draft" disabled>
        <XhAccordionHeader>
          <XhAccordionTrigger>
            <span>草稿（禁用）</span>
            <XhAccordionIndicator />
          </XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>这一项展不开。</XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="archived">
        <XhAccordionHeader>
          <XhAccordionTrigger>
            <span>已归档</span>
            <XhAccordionIndicator />
          </XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>从第一项按方向键，会直接跳到这里。</XhAccordionContent>
      </XhAccordionItem>
    </XhAccordionRoot>
  </div>
</template>

语气 ​

tone 落在展开态的标题上，六种语气各预置一项展开做对照

tone="brand"

收起态的标题不吃语气色。

tone="neutral"

收起态的标题不吃语气色。

tone="success"

收起态的标题不吃语气色。

tone="warning"

收起态的标题不吃语气色。

tone="danger"

收起态的标题不吃语气色。

tone="info"

收起态的标题不吃语气色。
<script setup lang="ts">
import {
  XhAccordionContent,
  XhAccordionHeader,
  XhAccordionIndicator,
  XhAccordionItem,
  XhAccordionRoot,
  XhAccordionTrigger,
} from "@xihan-ui/vue";

const tones = [
  { value: "brand", label: "品牌" },
  { value: "neutral", label: "中性" },
  { value: "success", label: "成功" },
  { value: "warning", label: "警告" },
  { value: "danger", label: "危险" },
  { value: "info", label: "信息" },
];
</script>

<template>
  <div
    style="
      display: grid;
      gap: 16px;
      grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    "
  >
    <XhAccordionRoot
      v-for="tone in tones"
      :key="tone.value"
      :tone="tone.value"
      :default-value="['open']"
    >
      <XhAccordionItem value="open">
        <XhAccordionHeader>
          <XhAccordionTrigger>
            <span>{{ tone.label }}（展开）</span>
            <XhAccordionIndicator />
          </XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>tone="{{ tone.value }}"</XhAccordionContent>
      </XhAccordionItem>
      <XhAccordionItem value="closed">
        <XhAccordionHeader>
          <XhAccordionTrigger>
            <span>{{ tone.label }}（收起）</span>
            <XhAccordionIndicator />
          </XhAccordionTrigger>
        </XhAccordionHeader>
        <XhAccordionContent>收起态的标题不吃语气色。</XhAccordionContent>
      </XhAccordionItem>
    </XhAccordionRoot>
  </div>
</template>

解剖 ​

部件名即 data-part 属性值，也是皮肤的选择器。加粗的是必备部件，不渲染它组件不工作（Web Components 适配器会在诊断通道上报 wc.missing-part）。

data-scope="accordion"：root · item · header · trigger · content · indicator

Props ​

属性类型必填说明
valuestring[]展开集合，给定即受控。
defaultValuestring[]
multipleboolean允许多项同时展开；false 时展开一项即收起其余。
collapsibleboolean允许把最后一个展开项收起，默认 false。
orientationOrientation方向键轴向，默认 vertical。
dirDirection文字方向，默认 ltr；影响水平轴上 ArrowLeft/ArrowRight 的语义。
tonestring语气：brand / neutral / success / warning / danger / info，决定用哪族颜色。
sizestring尺寸：sm / md / lg。
onValueChange(details: AccordionValueChangeDetails) => void展开集合变化回调。

状态机 ​

状态：idle

事件：ITEM.TOGGLE · VALUE.SET

connect API ​

useAccordion 产出的对象。getXxxProps() 铺到对应部件的宿主元素上，其余是可读状态与操作入口。

成员类型说明
valuestring[]当前展开集合，单开模式下长度 ≤ 1。
setValue(next: string[]) => void
isOpen(value: string) => boolean
getRootProps() => T['element']
getItemProps(props: AccordionItemProps) => T['element']
getHeaderProps(props: AccordionItemProps) => T['element']
getTriggerProps(props: AccordionItemProps) => T['button']
getContentProps(props: AccordionItemProps) => T['element']
getIndicatorProps(props: AccordionItemProps) => T['element']

键盘 ​

规格出处：W3C APG

按键生效条件行为
Space / Enterfocus in trigger, not disabled展开/收起该条目的 content
ArrowDown / ArrowRightfocus in trigger, 按键与 orientation 同轴（dir=rtl 时左右键语义互换）焦点移到下一个 trigger，末条不回绕
ArrowUp / ArrowLeftfocus in trigger, 按键与 orientation 同轴（dir=rtl 时左右键语义互换）焦点移到上一个 trigger，首条不回绕
Homefocus in trigger焦点移到首个 trigger
Endfocus in trigger焦点移到末个 trigger
Tab / Shift+Tabfocus in trigger按文档序进出：每个 trigger 都是独立 Tab 停靠点，无 roving tabindex
