TypeScript：注册品牌并提交视觉环境
import {
  brandId,
  createVisualEnvironmentController,
  registerBrand,
} from "@xihan-ui/tokens/runtime";

registerBrand("custom", "#0067ea");

const visual = createVisualEnvironmentController({
  root: document.documentElement,
  initial: {
    // 预览用的是浅色；跟随系统写 "system"
    mode: "light",
    brand: brandId("custom"),
    density: "comfortable",
    contrast: "default",
  },
});

能改什么 ​

设置改的是项目里怎么用
品牌色由种子色派生的整套 --xh-color-brand-50…950 原语导出的 [data-brand] 取值块，或运行时 registerBrand
明暗data-theme视觉环境控制器的 mode
密度data-density控制器的 density
对比度data-contrast控制器的 contrast
圆角原始阶梯 --xh-radius-sm / md / lg导出的 :root 覆盖

预设只是上面五项的一组取值，选中后照样可以逐项微调；与哪套预设完全一致，哪套就显示为选中。

品牌色只取种子的色相与彩度，明度曲线沿用基线，所以换任何种子，语义层（实心按钮、链接、选中态）的对比度保证都不变；种子本身的明暗不会被原样搬进来。圆角改的是原始阶梯，控件、表面、浮层三档形状语义跟着走，组件之间的层次关系保持不变。

接入 ​

把「CSS」一栏放进全局样式，或者只用「TypeScript」一栏在运行时注册品牌：两者给出的品牌色是同一套。明暗、密度与对比度属于视觉环境，按设计令牌与主题里的控制器提交，Vue 与 React 也可以经 XhConfigProvider 传入。

预览区本身就是一个局部视觉环境：它用 XhConfigProvider 的同一套机制把设置写到自己的根元素上，下拉、日期面板这类渲染到预览区之外的浮层也会带上同样的设置。项目里把控制器挂在根元素上，整站随之生效。
