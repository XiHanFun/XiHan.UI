架构总览
  • 🧠

    无头内核

    解剖、状态机与无障碍逻辑位于框架无关的内核，适配器只负责把属性写到宿主元素上，不重新实现任何行为。

    了解解剖与部件契约

  • 🔁

    一份行为，三种宿主

    Vue、React 组件与自定义元素运行同一个状态机、同一份 connect。跨适配器一致性套件逐帧比对归一化后的 DOM，验证框架无关。

    查看适配器

  • ♿

    无障碍是判据

    每个组件都有一份机读的键盘规格表，它同时是测试的分母，用例少覆盖一条即判套件失败。扫描运行在真实 Chromium 上。

    了解无障碍规格

  • 🎨

    样式与逻辑解耦

    皮肤只识别 data-scope / data-part 与状态属性，不识别框架与类名。令牌从 DTCG 源产出 CSS 变量，整体更换皮肤不需要修改 JS。

    了解皮肤与样式分层

  • 📦

    依赖面收敛

    全部库包都没有运行时第三方依赖。日期运算、浮层定位、代码着色、虚拟滚动、Web Components 响应式基类、流式 Markdown 均为自研。

    查看包与依赖关系

  • 🤖

    AI 对话内核

    SSE 读取、协议归一、parts 归约、会话 store 全部位于零 DOM 的内核，渲染部分交给消息流、日志、提示输入框、代码视图与流式 Markdown。

    了解 AI 对话内核
