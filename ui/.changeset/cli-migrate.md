**新增** `xihan-ui migrate <从版本> <到版本> [<路径>...]`：跨大版本升级时改写源码，从版本之后、到版本及之前的每个大版本依次套用一套规则。规则取自各版更新日志「升级须知」里能机改的改名：导入路径与搬了家的导出（5.0 的颜色、快捷键函数改从 `@xihan-ui/core` 引入）、组件与 Props 类型（轻提示并入通知时补 `preset="toast"`、分段控件并入单选组时补 `variant="segmented"`）、属性与事件（只在归属对上的组件标签里改，布尔开关换成取值，如 Tree 的 `multiple` → `selectionMode="multiple"`）、部件、Web Components 元素与 attribute、CSS 变量、关键帧与 `data-*` 属性；2.0 的整组件改名按两版公开面展开到每个部件、Props 类型与覆盖槽。改不了的报出文件与行号：写了表达式的属性、与原生同名的事件监听、改成另一种结构的组件，以及本大版本删掉、迁移后仍出现的名字（由各版公开面基线比对得出）。`--dry-run` 只列出不写回，`--check` 有要改的就以 1 退出，`--format json` 给出结构化结果。覆盖 1.x → 5.0 的四套规则；每套规则里的旧名、新名都由 `build/gen-migrations.mjs` 对着发版标签上的公开面基线逐条核对过。
