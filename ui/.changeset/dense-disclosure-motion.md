**新增** `trackDisclosureMotion`：密集展开（子层里排着多行、套不上单行网格的那种）按实测高度补间。展开时子层块尺寸从 0 补到实测高度、同帧淡入；收起时在原处放一个替身从原高度缩到 0、同帧淡出，播完即移除；父级的行距随高度一起让出，展开第一帧与收起最后一帧都不跳；收起中途再展开从替身此刻的高度接着长。开合按 `hidden`、`data-state="closed"` 或卸下来认，宿主的渲染写法不变。`hold()` 让接下来的批量变化当场落定，一次翻动超过三枝时也当场落定；`alongside` 让随别的节点一起来去的子层交给那边的列表动效。

**新增** `tweenBlockSize`：同一个盒子换一副排法时，从旧高度补到新高度；`hold` 里的离散样式整段保持，收回时把行数夹紧这类当场生效的排法推迟到补间播完。

**新增** `trackListMotion` 的 `enabled`：返回 false 的那一批新到条目直接呈现，不放替身、不补偿换位。

**修复** 树、树选择、JSON 查看器、侧导航内联子层与表格详情行的展开收起硬切：现在按上面的补间展开与收起，展开箭头随子层同时长、同曲线（`expand` / `collapse`、`disclosure`）转向。侧导航搜索换枝、折叠换装当场落定；虚拟滚动的树与表格不补。

**修复** 树形表格展开、收起子行硬切：由表格管展开（行声明了 `parentId` 或 `expandable`）时，新到的子行播 `xh-item-in`、同一批按到达顺序错开，收起的子行由替身留在原处淡出，下面的行从旧位置滑到新位置；排序、换页与刷新换来的整批行直接呈现。表体在接上之前的首帧带 `data-instant`。

**修复** Truncate 铺开与收回硬切：盒子高度从旧排法补到新排法，收回时多出来的行随盒子收进去，不先被一刀裁掉。

退场替身（列表离场与密集展开收起时留在原处的那一份）不算条目：`queryItems`、列表动效与换位补偿都跳过它，键盘导航越过它。
