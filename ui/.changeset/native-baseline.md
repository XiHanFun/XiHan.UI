**变更** 浏览器按标签给的缺省外观改由基线层（`xihan.reset`）统一收掉，库节点的样子不再取决于它渲染成什么标签、在哪个浏览器里：外边距、内衬、描边、圆角、底色归零，字色与字体改成继承，原生外观一律 `appearance: none`；链接不带下划线，列表不带项目符号，表格不带格间隙，字段集不带按内容撑开的最小宽度。只作用于带 `data-scope` 的库节点，特指度为零，皮肤与配方的任何声明都压得住，宿主页面自己的元素不受影响。

看得出来的变化：

- 库里渲染成 `<button>` 的部件此前仍是原生外观（`appearance: auto`），字色在皮肤没写时是浏览器的系统色，深色主题下不跟着换。现在一律是库自己的样子，字色继承。作者自己写的 `<button data-xh-part="…">`、`<a data-xh-part="…">` 同样如此。
- 图片裁切的缩放与旋转两根滑杆此前直接用浏览器的原生滑杆，各家浏览器各是一副样子。现在按库里滑块的样子自己画：细槽加品牌描边的圆拇指，聚焦环画在拇指上，禁用态退成中性色；行为仍归原生 `range`。`--xh-image-cropper-slider-accent` 现在是拇指描边的颜色；轨道与拇指的圆角可用新增的 `--xh-image-cropper-slider-track-radius`、`--xh-image-cropper-slider-thumb-radius` 覆盖。滑杆的输入盒高 24px（细指针命中下限），粗指针下放大到 44px。
- 搜索框自带的清除钮、Edge 密码框自带的显示密码钮改在这一层收（此前在字段配方里）。

皮肤体积：`reset.css` 从 1687 涨到 2033 字节（上面这组基线规则），`image-cropper.css` 从 10016 涨到 12954 字节（两家引擎的轨道、拇指与聚焦环各写一遍）。
