**新增** `aspect-ratio` 组件（宽高比）：按 `ratio`（宽 ÷ 高，缺省 1）留出一块盒宽随容器、高由比例算出的区域，直接子元素铺满它，图片与视频按 `cover` 裁切填满；Web Components 的 `ratio` 特性写法同 CSS 的 `<ratio>`（`16/9`）。
