图表的数据晚于尺寸到达时仍按首次出现入场，三个适配器的入场动画一致。原先内核只把「从未显示过场景」认作首次出现，Web Components 的 `data` 只走 JS property、总在元素连上并量完尺寸之后才赋值，数据到来被当成一次更新：漏斗图、雷达图不展开，层级图、桑基图反而按更新插值而不是淡入，饼图的标签、引导线与环形中心不等扫开，迷你图的末点不等笔尖；Vue 与 React 异步取数时也一样。

现在按正在显示的画面里有没有画得出来的数据标记来认：没有就是首次出现，数据到来播完整的入场；空态里已画出的坐标轴与网格从原处过渡，不重新淡入；还没有数据时不播。涉及直角坐标图、漏斗图、关系图、层级图、饼图、雷达图、桑基图与迷你图。
