**新增** GridList 网格列表组件：提供可选择行、行主操作和独立行内按钮的 grid/row/gridcell 语义，支持单选、多选、方向键与连打检索；与 Sortable 组合后支持指针和键盘拖动。Vue、React 与 Web Components 三端同时可用。新增皮肤约 6 kB，包含容器、选择标记、行内动作与状态样式。
