**新增** `@xihan-ui/designer-shell/locale` 补齐与 UI 内建语言包对应的各语言文案：`designerShellDeDE`、`designerShellEnUS`、`designerShellEsES`、`designerShellFrFR`、`designerShellJaJP`、`designerShellKoKR`、`designerShellPtBR`、`designerShellRuRU`、`designerShellZhTW`，加上原有的 `designerShellZhCN`。导出名与 UI 的语言包一一对应（`jaJP` 对 `designerShellJaJP`）。各产品把同一语言的这一份并进自己的语言包，宿主按语言合并即可。缺省文案仍是英文，`designerShellEnUS` 与缺省相同。
