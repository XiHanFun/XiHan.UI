首个公开版本：框架无关的 UI 基座。

自研薄 FSM 内核 + headless（anatomy / machine / connect）+ 设计令牌与主题运行时 + 样式层，
102 个组件在 Vue 与 Web Components 两套适配器上共用同一份内核，跨适配器一致性套件与
真实 Chromium 里的无障碍扫描、浮层定位契约全绿。

浮层定位、虚拟滚动、Web Components 响应式基类、代码着色、流式 Markdown 均为自研，
运行时不带第三方依赖。
