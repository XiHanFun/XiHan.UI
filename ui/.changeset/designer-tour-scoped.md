新手引导限在设计器的外框里：遮罩只盖外框，高亮框连同暗幕裁在外框里，页面别处照常可读可点，焦点不困在气泡里。同一页同时只有一个引导开着：`start()` 遇到别的引导开着时不开始、返回 `false`，`start({ force: true })` 先收起那一个再开始，用户手动开始时用它。窄屏时引导打开的抽屉排在引导之下，不再盖住提示框，换到别的步骤与引导收起时还原。通用步骤「设置」的 order 由 90 改为 900，排在各款与扩展的步骤之后收尾。外框新增 `openDrawer`，读写窄屏时开着的那侧抽屉。
