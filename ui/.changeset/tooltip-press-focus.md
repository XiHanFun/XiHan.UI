**修复** 按下带提示（Tooltip）的按钮后，提示收起又立刻被重新打开，而且之后指针移开也不收，要等按钮失焦。按下时提示让位给真正的操作，但点击同时把焦点带到按钮上，这次聚焦被当成键盘聚焦，提示又按「聚焦打开」展开，聚焦打开的提示不随指针移出收起。委托模式（`delegate`）早就挡掉了这次聚焦，普通模式没有。

现在两种模式一致：按下之后，点击带来的那次聚焦不再把提示打开。指针移开再回来，或者动了键盘之后再聚焦到按钮上，提示照常出现；键盘 Tab 到按钮上照旧立即展开。Vue、React 与 Web Components 三端同步生效。
