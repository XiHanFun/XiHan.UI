**新增** `format-input` 的 `mixed`（Web Components 写 `mixed` 特性）：几个对象一起编辑而取值各不相同时，种类控件一项都不选，下拉显示「多个值」的占位（文案 `translations.mixed`，十种内建语言包都有），参数行、样例与行内说明不铺；选一个种类（含「不设格式」）即按它新起一份格式说明派发，与当前值相同也派发。
