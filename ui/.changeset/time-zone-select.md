**新增** `TimeZoneSelect` 组件：Vue、React 与 Web Components 都可按 IANA 名、城市或 UTC 偏移检索时区，并按 `referenceTime` 显示 DST 偏移。

组件的候选生成与过滤位于 Headless，输入、列表、浮层、键盘、表单和无障碍关系复用 Combobox。新增组合根皮肤约 1 KB。
