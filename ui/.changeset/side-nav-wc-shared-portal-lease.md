**SideNav 折叠态弹出面板：整排 positioner 共用一份 Portal 租约，面板里的链接与嵌套分支各认自己的身份。**

Light DOM 版此前每个顶层分支各持一份租约、只搬展开的那一张，它会排到还留在原位的兄弟之后，部件序与 Vue / React 不一致；搬到落点后，面板里所有节点的身份都被记成顶层分支的 `value`——链接丢掉 `href`、`data-value` 变成分支名、选中态对不上、点链接派出的 `value-change` 带的是分支名，方向键弹出面板后也落不到第一行。现在任一面板可见（含退场中）就把整排定位层搬到落点、全部收起才精确归位，逻辑来源改为侧栏根；身份先按最近的归属容器认，只有搬走的定位层与面板本身才按分支记账。
