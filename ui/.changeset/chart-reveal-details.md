图表入场的细节：折线上的数据点等描线的笔尖扫到才出现；饼图的标签与引导线等扫开的边缘到了才出现，环形中心等整圈扫完再淡入；环形中心的合计首次出现从 0 数上去，数据变化或图例切换时从旧值滚到新值。延迟以入场时长的比例写在私有槽 `--xh-_chart-reveal-at` 上，由样式乘上 `--xh-motion-duration-reveal`，作者改时长、系统开减弱动效时一起缩放；减弱动效下数值直接到终值。数据层的标记多于 1000 个时不做几何插值，只淡入淡出。
