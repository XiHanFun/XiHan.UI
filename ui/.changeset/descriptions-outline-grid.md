Descriptions 描边档的网格修正两处。一是标签在左（平板宽起）时同一列的标签对齐：此前每格自成一个网格、标签列宽各取各的，上下行标签长短不一时标签与取值之间的竖线错开；现在根按列数排成「标签轨道 + 取值轨道」成对的网格，每格用子网格继承轨道（跨列的格跨 2 × 跨列数条轨道），同一列的标签宽度取这一列最长的那个，各列各取各的，`--xh-descriptions-label-w` 照旧能把标签轨道定成同一个宽。子网格要 Chrome 117 起，更早的引擎里每格仍按自己的标签定宽。二是格线不再按奇偶序号拼：此前有格写了 `span` 或最后一行不满时，后面的格左边线与上边线错位，行首的格与外框叠成两道，最后一行空着那半边的上方没有分隔线；现在格与格之间留一道线宽的间隙，每格只在行尾一侧与下方各画一道线，最右一列与最后一行朝外的那道由外框裁掉，最后一格不画行尾那道、与没摆满的空列连成一格。标签与取值之间的竖线也画进两条轨道之间的间隙，标签淡底不再垫在线下，线色与外框一致。外框的裁切由 `overflow: hidden` 换成 `overflow: clip`，根不再是滚动容器。
