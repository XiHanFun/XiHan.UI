**新增** `<xh-designer-palette>` 的物料可以带下级 `children`：组里有物料带了下级时，这一组用 `<xh-tree>` 显示，键盘与读屏按树的约定（一个 Tab 停靠点，上下键移动，左右键收起、展开，回车与空格激活），没有下级的组仍是一列按钮。带下级的物料缺省收起，展开状态按物料 id 保留；点选只派发 `item-activate`，树上不留选中的痕迹；上级与下级都能拖出，按在展开箭头上不起拖。

**新增** 物料的 `browseOnly`：照常显示、能用方向键走到，不派发 `item-activate`、不能拖出，用于只起分组作用的上级与只供查看的下级；用不了的物料仍写 `disabled`。

**变更** `searchable` 的搜索同时匹配名称与说明（`description`），命中的物料连同它的上级一起展开显示，清空后回到原来的展开状态。
