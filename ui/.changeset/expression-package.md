新增 `@xihan-ui/expression`：受限表达式语言，供表单联动与公式、报表公式、打印格式化、流程条件共用。零运行时依赖、import 无副作用、不碰 DOM，不使用 `eval` 或 `new Function`。

- `parse` 把源码解析成可 JSON 序列化的语法树；`check` 静态检查未知标识符、未知函数、实参个数与禁止的成员名；`compile` 两步合一；`evaluate` 对数据求值。问题一律是问题码加源码区间，不带文案，表达式或数据的问题以结果返回，不抛异常。
- 文法：字面量、字段引用与成员访问、算术、比较、带短路的三值逻辑、条件运算与函数调用；对列表取成员是逐元素投影，`SUM(items.amount)` 可以直接写。
- 类型规则写死，没有隐式转换。数值按十进制精确运算（34 位有效数字，四舍六入五成双），日期不带时区，`NOW()` 只读宿主传入的时间，同样的输入永远得到同样的结果。
- 内置逻辑、数学、聚合、文本与日期函数；`createFunctionTable` 可只启用部分内置函数，并登记宿主自己的函数。
- 步数、深度、源码长度与字符串长度都有上限；只读宿主数据的自有数据属性，`__proto__`、`constructor`、`prototype` 一律禁止。
- 附带跨实现一致性用例，其他语言的实现逐条比对即可复刻同样的语义。
