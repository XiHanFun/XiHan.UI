首次发布：画布式设计器共用的界面零件，只出 Web Components（没有 Vue 与 React 版本）：设计器外框（面板停靠、浮出、收成标题条，整份布局存进设置）、属性面板、物料面板与拖放、页面结构、历史记录、问题列表、小地图、变换覆盖层与它的上下文工具条和尺寸徽标、标尺与参考线、设置对话框（含帮助、快捷键与关于）、导入字段、JSON 编辑、新手引导、命令工具栏，以及扩展登记的面板与命令。打印、流程、表单、报表四款设计器用同一套零件，名字、手势与事件一致。样式随包发 `style.css`，配无层组件皮肤时改引 `style.unlayered.css`；各语言文案在 `@xihan-ui/designer-shell/locale`，与 UI 的内建语言包一一对应。用法见文档站「设计器零件」。
