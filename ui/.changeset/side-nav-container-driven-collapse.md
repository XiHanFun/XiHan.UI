**修复** 侧导航的宽度交给外层容器时，收起与展开不等宽度过渡：`--xh-side-nav-w` 与 `--xh-side-nav-collapsed-w` 设成 `100%`、由外层侧栏自己过渡宽度，导航根上没有过渡，排布当场换成图标栏。收起时侧栏还宽着，行文字就被裁掉；展开时侧栏还没长开，文字就先淡入。

现在换排布前，除了导航根自己的过渡，还等祖先链上改盒宽的过渡（`width`、`inline-size` 及其上下限、`flex-basis` 等）走完：收起时文字先淡出、落定才裁掉，展开时容器长开之后文字才淡入；减弱动效下宽度令牌是 1ms，照旧即刻落定。修在 Headless，Vue、React 与 Web Components 三端同步生效。
