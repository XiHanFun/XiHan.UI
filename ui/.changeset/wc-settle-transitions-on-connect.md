元素插进文档后、或往已经连接的元素里放进新部件后，紧接着有代码同步读了布局（`getBoundingClientRect`、`getComputedStyle`、`clientWidth`）时，作者写好的部件不再从浏览器缺省样式播过渡到皮肤色：此前接线（`data-scope`、`data-part` 与家族配方的属性）要等微任务里的那一轮更新才写，浏览器在读布局那一刻按还没接线的缺省样式为部件算出过渡起点，看起来是插进来先带一圈深色边框、过一会儿才恢复；新建插入、移出后再插回、往已连接的元素里追加或整批换掉部件都是如此。现在元素每次发现部件时记下其中还没接线的，同一任务里的接线都跑完后，统一取消这些部件身上已经起播的 CSS 过渡，部件直接呈现皮肤样式；之后的状态变化照常过渡，关键帧动画不受影响，更新的时机与次序不变。
