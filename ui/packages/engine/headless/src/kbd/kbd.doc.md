# 键帽

显示一个键名，不注册键盘监听。`Mod` 在 Mac 上显示为 ⌘，其他平台显示为 Ctrl。

## 何时使用

- 表示单个键。
- 展示按下或禁用状态。

## 何时不用

- 快捷键组合使用[键帽组](./kbd-group)。
- 快捷键监听使用[快捷键](./hotkeys)。
- 代码和命令使用[代码视图](./code-view)。

## 特性

- 渲染原生 `kbd` 元素。
- 平台键名由 Headless 统一格式化。
- `pressed` 只表示外部传入的按下状态。
- 提供三档尺寸和 compact 密度。

## 无障碍

- 符号键通过 `aria-label` 提供可读名称。
- 在 KbdGroup 内由整组统一朗读。

## 组合

- 可放在按钮、菜单项和说明文字中。
- 多个键使用 KbdGroup。

## 最佳实践

- 跨平台快捷键使用 `Mod`。
- 仅在动作激活时设置 `pressed`。

## 反模式

- 不要用 Kbd 代替按钮或菜单项。
- 不要在 Kbd 上注册快捷键。
