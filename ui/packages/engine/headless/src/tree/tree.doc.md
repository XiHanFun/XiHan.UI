# 树

层级数据的展开与选择：分支可展开，节点可选。

## 何时使用

- 文件目录、组织架构、权限节点等任意深度的层级数据。
- 需要在树上多选并处理父子级联。
- 一边勾选一批节点做批量操作，一边点开某一项看详情（`checkable`）。

## 何时不用

- 树只用于选一个值时，使用[树选择](./tree-select)，它把树收进浮层。
- 层级规整、层数固定且只为选值时，使用[级联选择](./cascader)。
- 数据是扁平的时，使用[列表](./list)或[表格](./table)。

## 特性

- 展开集合与选中集合两套值各自可受控。
- `defaultExpandAll` 让树一挂上就展开全部已有子项的分支；数据是后取的（挂载时 `collection` 还是空的）就等第一份数据到了再展开，只此一次。还没取回子项的懒分支不算在内，不会一挂上把每个懒分支都请求一遍；同时给了 `defaultExpandedValue` 时以它为准。运行中用 `expandAll()` / `collapseAll()`：Vue 默认插槽与 React 函数式 children 的载荷里有，自定义元素是同名方法；受控时把 `expandableBranches(collection)`（`@xihan-ui/headless` 导出）写进 `expandedValue` 即全部展开，写空数组即全部收起。
- `filterText` 给检索词，树按它裁到只剩命中的那几枝：命中的节点连同整棵子树留下，祖先保留并自动展开；搜索里的展开单独记，不改写 `expandedValue`，清空检索词即回到原来的展开态。匹配规则缺省是标签大小写不敏感包含，`filter` 可换。树自己不带输入框，检索词由作者的输入框给；手写的整棵树里没命中的节点由连接层带 `hidden` 收起，标准结构只铺留下的那几枝。一枝都没命中时空态露面，要分「没有数据」与「没有命中」读载荷里的 `searching`。搜索时节点不可拖。与[树选择](./tree-select)的浮层内搜索同一套裁剪。
- `variant` 决定外框形态，默认 `ghost`，树直接落在页面或宿主面上；`outline` 加一圈描边与底色，`subtle` 换成淡底无描边。
- `size` 取 `sm` / `md` / `lg`，默认 `md`，走集合家族的尺寸档：行高、行内内衬、字号、展开箭头与对号盒、拖拽把手与层级缩进一起随档。
- 选择模式 `selectionMode`：缺省 `single` 单选；`multiple` 点击与确认键切换，按住 Shift 点击把锚点到这一项那一段并进来；`extended` 照文件管理器，点击与确认键换成这一项，按住 Ctrl / Cmd 点击或按 Ctrl / Cmd + Space 切换这一项，按住 Shift 点击选锚点到这一项那一段（同时按 Ctrl / Cmd 则并进）。锚点是最近一次点击或切换的那一项；选中从外面换了（受控时宿主另写了值、`setSelection`、初始的选中），锚点落到多出来的最后一项，清空了就没有锚点。级联勾选只在 `multiple` 下生效。
- `checkable` 让勾选与选中各管一件事：行首勾选框与空格键只改勾选集合 `checked`（批量删除、批量授权），点行与确认键照 `selectionMode` 选中（单选即当前项，用来看详情），两份集合各自可受控、各报各的事件。勾选框不占 Tab 位，焦点仍在所在的行上；树项用 `aria-checked` 报勾选、`aria-selected` 报选中。行首已是勾选框，选中改由品牌淡底行面表达。`cascade` 与 `checkedStrategy` 此时作用在勾选集合上。不开 `checkable` 时，`multiple` 档的点行本身就是勾选，适合纯勾选清单。
- 选中与[树形选择器](./tree-select)同一种读法：行不换面。单选与 `extended` 在行尾画对号；`multiple`（含级联）换成行首勾选框，排在展开箭头之后、文字之前，一眼看得出点行是勾上这一项、而不是换掉已选的那一项。分支行也摆 `item-indicator`，级联下的半选在方框里画横杠。
- `cascade` 与 `checkedStrategy` 决定勾选父节点是否带子节点，以及回显给哪一层。
- 支持只让叶子进选中集合、子节点异步加载、拖放换父。拖放与 Alt + 方向键落下之后，宿主写回 `collection` 的那一次重排里，行从旧位置滑到新位置（换了父被重建的节点按节点值认回）；落点线取品牌实心色，与表格、排序同一种。
- 展开与选中分开：点行只选中，展开归箭头与左右方向键；`expandOnClick` 打开后点整行才顺带展开。
- 节点可逐条声明语气，不向下传导；叶子行与分支行同样表达。
- 节点可写副文本，第 2 行放一句解释，不进连打检索串。
- 开着 `nodeReorderable` 时，节点数据写 `draggable: false` 的那一个拖不起来：指针按住、Alt + 方向键都不搬它，行上不写 `data-draggable`，它的拖拽把手报禁用；它照常能选、能展开，也照样是别的节点的落点。不向下传导，它的子节点各自照常可拖。大纲里的区域、页、页眉这类「能选能当容器、自己不能挪」的行用它，不必禁用。
- 节点行尾留一格给作者（计数、徽标），排在对号之前；行首归展开箭头与拖拽把手，`multiple` 的勾选框紧随其后。
- 空（`empty`）与在途（`loading`）两个相位各有部件，都放在 `root` 内作为 `tree` 的兄弟；`loading` 为真时树报告 `aria-busy`，空态让位。在途分两种：还没有节点时在途占位露面，一枚加载环排在文案之前；已有节点时重新取数不换成占位，行保留上一帧淡下，取完再淡回。
- `leafOrientation` 按结构判据横排：子节点全是叶子的层跟随它，其余始终竖排。
- 懒分支：节点写 `hasChildren: true` 且不给 `children`，首次展开时调 `loadChildren({ node, signal })` 取它的直接子项，取回的子项由组件暂存、不写回 `collection`；在途时分支报告 `aria-busy`、展开箭头换成转圈（减弱动效下停住）。收起会中止在途的一轮，收起再展开不重复请求。失败与「取回空数组」是两个终态：失败露出说明与重试钮，再次展开不自动重试，点重试钮或在分支上按 Enter / Space 才重发；空数组露出空结果。在途、失败说明、重试钮与空结果四个部件由组件在分支里自己补，手写结构时也一样。取数与树选择、级联选择同一套规则，事件是 `branch-load-start` / `branch-load` / `branch-load-error`。
- 取数由作者自己编排时，把在途的分支写进 `loadingValue`：同样报告 `aria-busy` 并换成转圈，回来后写回 `collection` 并移出。
- `lines` 打开连接线：父节点展开箭头的中线向下引一道竖线，每个子节点从竖线横出一段接到行首（分支接到展开箭头，叶子穿过占位那一格接到正文前），最后一个子节点的竖线止于它那一行的中线；展开着的分支，竖线沿它的整棵子树接到下一个兄弟。颜色取内部分隔线（`--xh-tree-line-color`），只是外观，不改结构与键盘。顶层节点没有父节点可连，不画线；线画在嵌套的子层里，虚拟化平铺渲染的行不画。
- 节点上标 `childrenOrientation: 'horizontal' | 'vertical'` 指定该层子节点的排列方向，优先于 `leafOrientation`；标 `vertical` 可以把树级的 `horizontal` 改回竖排。根层不受影响，始终竖排。

## 组合

- 不写结构时照标准结构铺：标题（给了 `label` 时）与整棵树，分支是一行控制行（展开箭头、文字、副文本、选中标记）加一层子层，叶子是文字、副文本与选中标记；收起的分支照样铺出子层，节点按值复用。Vue / React 不写默认插槽与 Web Components 不写部件（或只写 root）时生成的节点出自同一个结构函数。行尾内容、自定义指示符、拖动把手与播报区、空态与在途占位不在标准结构里，要用时整棵手写。
- 前缀放[图标](./icon)，行尾放[菜单](./menu)；放入[分栏](./splitter)的一侧。
- 大树把 `visibleNodes` 的长度交给 [Virtualizer](./virtualizer)，并把其 `collectionVirtualizer` 回传给根；展开收起后同步更新 `count`。

## 最佳实践

- 大树必须虚拟化或按需加载，一次展开全部会卡顿。
- 级联勾选的策略与后端约定一致。
- 只需要某一层横排时标 `childrenOrientation`，不开启树级 `leafOrientation`：后者按结构判断，其他恰好“子节点全是叶子”的层也会横排，并随数据增减变化。

## 反模式

- 展开状态不持久，用户每次进入都要重新展开。
- 拖放换父没有落点提示。
