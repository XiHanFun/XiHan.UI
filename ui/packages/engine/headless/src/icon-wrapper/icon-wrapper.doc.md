# 图标块

为图标提供统一的背景容器。

## 何时使用

- 突出功能入口、状态或分类图标。
- 统一一组图标的视觉尺寸。

## 何时不用

- 只需显示图标时，使用[图标](./icon)。
- 显示人物或组织形象时，使用[头像](./avatar)。

## 特性

- 支持三档尺寸。
- 支持四种变体和六种语义颜色。

## 组合

- 通常与[图标](./icon)、[空状态](./empty-state)或[列表](./list)组合使用。

## 最佳实践

- 同组图标块使用一致的尺寸和变体。
- 图标块不承载交互；可点击操作使用[按钮](./button)。

## 反模式

- 不要用图标块替代[徽标](./badge)显示计数。
