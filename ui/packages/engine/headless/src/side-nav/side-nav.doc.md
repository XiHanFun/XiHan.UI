# 侧栏导航

用于组织应用的主要导航入口。

## 何时使用

- 管理后台或控制台的主导航。
- 导航包含分组或可展开的子级。

## 何时不用

- 顶部横向导航，使用[导航菜单](./navigation-menu)。
- 文件或组织结构，使用[树](./tree)。

## 特性

- 支持分组、嵌套分支与当前项高亮。
- `accordion` 限制同一层级只展开一个分支。
- 折叠后保留图标入口，子级在浮层中展示。
- 方向键上下移动，左右键展开或收起分支。

## 无障碍

- `list` 与 `branch-content` 使用列表语义。
- 将文字放入 `branch-text` 或 `link-text`，确保折叠后仍有可访问名称。
- 装饰图标使用 `aria-hidden="true"`。

## 组合

- 放入[布局](./layout)的侧栏区域。

## 最佳实践

- 导航层级保持在两到三级。
- 折叠模式下为每个入口保留清晰图标。

## 反模式

- 不要为单个入口创建分支。
- 不要在折叠时卸载导航树。
