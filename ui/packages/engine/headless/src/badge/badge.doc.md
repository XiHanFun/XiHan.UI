# 徽标

一小块表达状态、分类或计数的标记。

## 何时使用

- 状态标记（进行中 / 已完成 / 已失效）。
- 分类标签、计数角标。

## 何时不用

- 用户可以点它来筛选或删除：那需要交互语义，组件本身只是展示，交互要自己接。
- 它承载的是一个实体身份、并且用户要能把它摘掉：用[标签](./tag)——关闭钮与显隐状态它自带。
- 表达进度：用[进度条](./progress)。
- 是一个可开关的选项：用[切换按钮](./toggle)。

## 特性

- 形态 · 语气 · 尺寸三轴与其余组件同源。
- 可以带图元、可以做成可关闭标签、可以挂成角标。
- 配色可以逐实例覆盖，不受语气表限制。

## 组合

- 挂在[头像](./avatar)、[按钮](./button)、[标签页](./tabs)的标签上做角标。

## 最佳实践

- 状态别只用颜色区分：红绿色觉障碍的用户看不出差别，文字必须说清楚。
- 计数超过阈值就写成 99+，别让徽标撑变形。

## 反模式

- 一屏里到处都是高饱和度的徽标：全都在喊，等于都没喊。
- 用徽标承载长句子。
