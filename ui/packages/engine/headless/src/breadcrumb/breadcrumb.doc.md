# 面包屑

显示当前页面在信息层级中的位置。

## 何时使用

- 页面具有明确的父子层级。
- 用户可能从搜索或外链直接进入深层页面。

## 何时不用

- 扁平页面不需要面包屑。
- 流程进度使用[步骤条](./steps)。

## 特性

- `collection` 可直接生成完整路径，也支持手写部件。
- `maxItems` 将过长路径的中间层折叠为省略号。
- 默认分隔符为箭头，可通过插槽或渲染函数替换。
- 当前页使用 `aria-current="page"`，不参与键盘导航。

## 组合

- 通常放在页头或正文标题之前。

## 最佳实践

- 当前项使用清晰的页面标题，避免“详情”等泛化名称。
- 同页有多个 `nav` 地标时给面包屑单独的 `aria-label`。

## 反模式

- 不要用面包屑表示浏览历史。
- 当前项不要链接到自身。
