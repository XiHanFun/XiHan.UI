# 分隔线

分隔相关内容或内容分组。

## 何时使用

- 分隔菜单、列表、工具栏或表单区域。
- 在分隔线中显示分组标题。

## 何时不用

- 只需留白时使用间距。
- 每项都需要分隔时优先调整列表结构。

## 特性

- 支持水平和垂直方向。
- 支持默认、弱化、强调和虚线样式。
- 支持居中或靠边的分组标题。
- `decorative` 可将纯视觉分隔线移出无障碍树。

## 组合

- 可用于[菜单](./menu)、[工具栏](./toolbar)和[面包屑](./breadcrumb)。

## 最佳实践

- 纯视觉分隔线使用 `decorative`。
- 垂直分隔线的父容器应有明确高度。

## 反模式

- 不要用分隔线替代语义标题。
- 不要在同一区域堆叠过多分隔线。
