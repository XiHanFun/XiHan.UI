# 回到顶部

滚动超过指定距离后显示返回入口。

## 何时使用

- 用于长页面或独立滚动区域。

## 何时不用

- 短页面不需要返回入口。
- 多个悬浮操作使用[浮动按钮](./float-button)。

## 特性

- `visibilityHeight` 设置显示阈值。
- `behavior` 支持平滑或立即返回。
- 默认使用悬浮玻璃表面，也可通过 `variant` 调整外观。
- 减少动效、减少透明度与强制色模式会自动降级。

## 组合

- 指定 `target` 后监听并滚动该容器；未指定时作用于页面。

## 最佳实践

- 避开固定工具条和移动端手势区。
- 保持默认的按需显示，不要在页面顶部常驻。

## 反模式

- 不要在短页面或已有返回入口的位置重复使用。
